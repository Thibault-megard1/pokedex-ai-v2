# Zone Music Files

Place your music files in this directory with the following names:

## Required Music Files

- **pallettown.mp3** - Background music for Pallet Town
- **lab.mp3** - Background music for Professor Oak's Lab
- **route1.mp3** - Background music for Route 1
- **viridianforest.mp3** - Background music for Viridian Forest
- **route2.mp3** - Background music for Route 2

## Format

- Preferred format: MP3
- Alternative formats: WAV, OGG (update musicManager.ts if using different extensions)
- Recommended: Loop-friendly tracks (seamless loops)
- Bitrate: 128-192 kbps recommended for balance between quality and file size

## Volume Control

Music volume can be adjusted in the admin settings panel during gameplay.
Default volume is 50%.

## How Music Works

- Music automatically plays when entering a zone
- Smooth fade transitions (1 second) between zones
- Music loops continuously
- Pauses during battles (can be customized)
